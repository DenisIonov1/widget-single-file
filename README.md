## Виджет чат

#### Легковесный, адаптивный виджет чата для сайтов недвижимости с интеграцией AI-ассистента. Виджет имитирует живое общение с менеджером, поддерживает подсказки, анимацию набора текста и полностью кастомизируется через CSS.
## Функционал 
* #### Адаптивный дизайн: Корректно отображается на десктопах, планшетах и мобильных устройствах.
* #### Имитация живого общения:
  * Анимация "печатания" с пульсирующими точками и иконкой карандаша.
  * Таймер обратного отсчета перед ответом ("Менеджер ответит через X сек").
  * Плавные анимации появления сообщений.
* #### Интерактивность:
  * Быстрые кнопки-подсказки (Suggested Actions) для старта диалога.
  * Поддержка отправки сообщений по Enter (без Shift).
  * Блокировка ввода во время ожидания ответа от бэкенда.
* #### Интеграция с API:
  * Отправка сообщений на вебхук.
  * Генерация уникальных chatId и messageId для трекинга сессий.
  * Обработка ошибок сети.
